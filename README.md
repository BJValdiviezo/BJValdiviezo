## 🔄 Mi enfoque como QA

```text
REQUERIMIENTO
      │
      ▼
ANÁLISIS + RIESGOS
      │
      ▼
ESCENARIOS DE PRUEBA
      │
      ▼
EJECUCIÓN
      │
 ┌────┴────┐
 ▼         ▼
PASS     DEFECTO
            │
            ▼
        BUG REPORT
            │
            ▼
          RETEST
            │
            ▼
        REGRESSION
            │
            ▼
           OK
```

> **QA no es solamente encontrar bugs.**
> También significa comprender los requerimientos, detectar riesgos y ayudar al equipo a prevenir problemas antes de que lleguen al usuario.
