## 🧪 Sobre mí

Soy **QA Functional & Automation Analyst** con sólido perfil técnico y orientación a la calidad de software integral. Combino metodologías de testing funcional y exploratorio con el diseño de frameworks de automatización escalables y mantenibles.

Cuento con experiencia en pruebas E2E (Web y Mobile), validación de APIs REST, testing de bases de datos mediante SQL/SOQL, accesibilidad web y proyectos en el ecosistema Salesforce.

Mi enfoque como QA abarca la comprensión del negocio, identificación temprana de riesgos, diseño estratégico de escenarios, documentación clara de evidencias y prevención de defectos antes de que impacten en producción.
